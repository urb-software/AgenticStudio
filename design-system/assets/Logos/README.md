# Logos

- `agent-studio-mark.svg`: the hexagon mark, white on an `accent-solid` (#7c3aed) tile with a 16/64 corner radius. Use at 24–32px in the sidebar and login card, and as the favicon. Works on both themes as is.
- `agent-studio-lockup.svg`: the mark plus “Agent Studio” in Inter semibold, ink #18181b, for light backgrounds. On dark backgrounds set the word in `text` (#ececf1) or pair the mark with live text instead.

Keep clear space of half the tile on every side. Don't recolour the tile, outline the mark, or set the name in another face.
