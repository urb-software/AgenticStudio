# Prototype source

The markup, CSS and mock data of the clickable prototype (all screens: login, projects, project detail, agents, skills, workflows, executions, run detail, preview, MCP, settings).

This file runs only inside the design canvas (it needs the canvas runtime), so it won't open in a browser on its own. Use it as a porting reference: the `<style>` block holds every class, and the markup shows each screen's structure. To click through the prototype, open it on the canvas.
