# EmptyState

What a list shows when it has nothing, or when it failed to load. Every list in the app has both.

- Empty: title says what to do ("Create your first project"), one sentence explains what the thing is, one primary action.
- Filtered to nothing: "No runs match these filters" plus "Clear filters".
- `tone="error"`: what failed (the request and status in mono), and a Retry button.
