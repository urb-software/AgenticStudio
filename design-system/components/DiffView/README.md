# DiffView

Unified diff of one file. Header: path in mono, green +additions and red −deletions. Rows: old and new line numbers, a sign column, the text; additions on run-succeeded-soft, deletions on run-failed-soft, hunk headers on run-running-soft. Pair it with a file tree on the left (selected file on accent-soft). A split view puts old and new side by side with hatched filler where one side is empty.
