# Banner

Inline, persistent message inside a page, card, dialog or drawer. It stays until the condition changes.

- `warning`: blocks or limits something ("Not validated — automated execution disabled", "Too many attempts. Try again in 60s").
- `danger`: a server error the user can act on: problem+json **title** in bold, then the detail.
- `info` / `success`: confirmations that belong to the page ("Merged to dev as c81d0e4").

Lead with a bold summary, then one sentence. For transient confirmations use `Toast`.
