# Icon

Line icons in the lucide style: 24px grid, 2px stroke, round caps, drawn with `currentColor`. Shown at 16px in UI, 14px (`sm`) in chips and dense rows, 20px (`lg`) in empty states and error cards.

In the Next.js app use `lucide-react` directly (`Bell`, `GitBranch`, `ShieldCheck`, `GitMerge`, `FlaskConical`, `Terminal`…); this component ships the subset the prototype uses so previews work without a package. Icons are always paired with a label or an `aria-label`.
